## 3. CAN 物理层与 ID 结构

| 项目 | 参数 |
|---|---|
| 总线 | CAN 2.0 |
| 帧格式 | **扩展帧（29 位 ID）** |
| 波特率 | **1 Mbps**（出厂默认） |

### 3.1 29 位 ID 拆解

| 位域 | 大小 | 含义 |
|---|---|---|
| bit28–bit24 | 5 bit | **通信类型** |
| bit23–bit8 | 16 bit | **数据区 2** |
| bit7–bit0 | 8 bit | **目标地址**（电机 CAN ID） |

```c
ext_id = (comm_type << 24) | (extra_data << 8) | motor_id;
```

**方向约定：**

- 主机 → 电机：`bit7~0` = 电机 ID，`bit23~8` 低字节 = 主机 ID（主机地址，建议 0xFD）
- 电机 → 主机：`bit7~0` = 主机 ID，`bit23~8` 低字节 = **电机 ID**

> 判断一条反馈帧是不是目标电机发的，要看 `(id >> 8) & 0xFF`，不是 `id & 0xFF`。

## 4. 通信类型总表

| 类型 | 名称 | 方向 |
|---|---|---|
| 0 | 获取设备 ID | 主机→电机 |
| **1** | **运控模式控制指令（MIT）** | 主机→电机 |
| **2** | **电机反馈数据** | 电机→主机 |
| **3** | **电机使能运行** | 主机→电机 |
| **4** | **电机停止运行**（Byte0=1 清故障） | 主机→电机 |
| 6 | 设置机械零位 | 主机→电机 |
| 7 | 设置 CAN ID | 主机→电机 |
| 17 | 单个参数读取 | 主机→电机 |
| 18 | 单个参数写入（掉电丢失） | 主机→电机 |
| 21 | 故障反馈帧 | 电机→主机 |
| 22 | 数据保存帧 | 主机→电机 |
| 23 | 波特率修改（重新上电生效） | 主机→电机 |
| 24 | 主动上报开关 | 主机→电机 |
| 25 | 协议切换（私有 / Canopen / MIT） | 主机→电机 |

## 5. 各通信类型详解

### 5.1 类型 0：获取设备 ID

```
ID   = (0 << 24) | (host_id << 8) | motor_id
Data = 8 字节 0x00
```

应答：

```
ID   = (0 << 24) | (motor_id << 8) | 0xFE
Data = 64 位 MCU 唯一标识符
```

### 5.2 类型 1：运控模式控制指令（最常用）

```
ID   = (1 << 24) | (torque_u16 << 8) | motor_id
Data = 8 字节，高字节在前（大端）
```

| 字节 | 内容 | 映射 |
|---|---|---|
| Byte0–1 | 目标角度 `u16` | 0–65535 ↔ **-12.57 ~ +12.57 rad**（±4π） |
| Byte2–3 | 目标角速度 `u16` | 0–65535 ↔ **-15 ~ +15 rad/s** |
| Byte4–5 | Kp `u16` | 0–65535 ↔ **0.0 ~ 5000.0** |
| Byte6–7 | Kd `u16` | 0–65535 ↔ **0.0 ~ 100.0** |
| ID 的 bit23–8 | 前馈力矩 `u16` | 0–65535 ↔ **-120 ~ +120 Nm** |

**编码函数（手册附录原函数）：**

```c
int float_to_uint(float x, float x_min, float x_max, int bits) {
    float span = x_max - x_min;
    float offset = x_min;
    if (x > x_max) x = x_max;
    else if (x < x_min) x = x_min;
    return (int)((x - offset) * ((float)((1 << bits) - 1)) / span);
}
```

等价写法：

```c
p_u16  = float_to_uint(p,  -12.57f, 12.57f, 16);
v_u16  = float_to_uint(v,  -15.0f,  15.0f,  16);
kp_u16 = float_to_uint(kp,   0.0f, 5000.0f, 16);
kd_u16 = float_to_uint(kd,   0.0f,  100.0f, 16);
t_u16  = float_to_uint(t, -120.0f, 120.0f, 16);
```

**控制律（手册 §4.3.1）：**

```
t_ref = Kd * (v_set - v_actual) + Kp * (p_set - p_actual) + t_ff
```

`t_ref` 内部折算成期望 Iq 电流，由电流环输出。

**手册给的三个调试场景：**

| 目标 | p_set | v_set | Kp | Kd | t_ff |
|---|---|---|---|---|---|
| 恒速 1 rad/s | 0 | 1 | 0 | 1 | 0 |
| 纯阻尼 | 0 | 0 | 0 | 1 | 0 |
| 到位 5 rad | 5 | 0 | 1 | 1 | 0 |

### 5.3 类型 2：电机反馈数据

```
ID   = (2 << 24) | (extra << 8) | host_id
Data = 8 字节，高字节在前（大端）
```

| 字节 | 内容 | 映射 |
|---|---|---|
| Byte0–1 | 当前角度 `u16` | 0–65535 ↔ **-12.57 ~ +12.57 rad** |
| Byte2–3 | 当前角速度 `u16` | 0–65535 ↔ **-15 ~ +15 rad/s** |
| Byte4–5 | 当前力矩 `u16` | 0–65535 ↔ **-120 ~ +120 Nm** |
| Byte6–7 | 温度 `u16` | **实际温度 = 值 × 0.1 ℃** |

**`extra`（bit23–8）里的状态位：**

| 位（完整 ID） | 位（extra 视角） | 含义 |
|---|---|---|
| bit8–15 | bit0–7 | 当前电机 CAN ID |
| bit16 | bit8 | 欠压故障 |
| bit17 | bit9 | 三相电流故障 |
| bit18 | bit10 | 过温 |
| bit19 | bit11 | 磁编码故障 |
| bit20 | bit12 | 堵转过载故障 |
| bit21 | bit13 | 未标定 |
| bit22–23 | bit14–15 | 模式：0=Reset，1=Cali，2=Motor（运行） |

> **注意**：0.4.1.0 之后类型 2 的位置改为周期性 `-4π ~ 4π`，可用此记圈。

### 5.4 类型 3：使能

```
ID   = (3 << 24) | (host_id << 8) | motor_id
Data = 8 字节 0x00
```

应答：类型 2 反馈帧。

### 5.5 类型 4：停止

```
ID   = (4 << 24) | (host_id << 8) | motor_id
Data = 8 字节 0x00（正常停止）
       若 Byte0 = 0x01，则清故障
```

应答：类型 2 反馈帧。

### 5.6 类型 6：设置机械零位

```
ID   = (6 << 24) | (host_id << 8) | motor_id
Data = Byte0 = 0x01，其余 0
```

> 手册 §4.2.6：**CSP 和运控模式可以标零，PP 模式标零会被屏蔽。**

### 5.7 类型 7：设置 CAN ID

```
ID   = (7 << 24) | (new_id << 16) | (host_id << 8) | motor_id
Data = 8 字节 0x00
```

注意新 ID 在 **bit23–16**，不是 bit23–8。

### 5.8 类型 17：单个参数读取

```
ID   = (17 << 24) | (host_id << 8) | motor_id
Data = Byte0–1: index（低字节在前）
       Byte2–3: 0x0000
       Byte4–7: 0x00000000
```

应答：

```
ID   = (17 << 24) | (motor_id << 8) | host_id
Data = Byte0–1: index
       Byte2–3: 0x0000
       Byte4–7: 参数值（低字节在前）
ID 的 bit23–16 = 0x00 读取成功，0x01 读取失败
```

### 5.9 类型 18：单个参数写入

```
ID   = (18 << 24) | (host_id << 8) | motor_id
Data = Byte0–1: index（低字节在前）
       Byte2–3: 0x0000
       Byte4–7: 参数值（低字节在前，不足 4 字节补 0）
```

**所有参数读写都是小端；只有类型 1 / 2 的数据区是大端。**

应答：类型 2 反馈帧。

> **写入掉电丢失**，需要再发类型 22 保存。

### 5.10 类型 21：故障反馈帧

```
ID   = (21 << 24) | (motor_id << 8) | host_id
Data = Byte0–3: fault 值（非 0 有故障）
       Byte4–7: warning 值
```

fault 位定义：

| bit | 含义 |
|---|---|
| 16 | A 相电流采样过流 |
| 14 | 堵转过载算法保护 |
| 9 | 位置初始化故障 |
| 8 | 硬件识别故障 |
| 7 | 编码器未标定 |
| 5 | C 相电流采样过流 |
| 4 | B 相电流采样过流 |
| 3 | 过压（>60V） |
| 2 | 欠压（<12V） |
| 1 | 驱动芯片故障 |
| 0 | 过温（>145℃） |

warning 位 0：过温预警。

### 5.11 类型 22：数据保存

```
ID   = (22 << 24) | (host_id << 8) | motor_id
Data = 0x01 0x02 0x03 0x04 0x05 0x06 0x07 0x08
```

> 注意：**不是全 0**。手册明确要求这 8 个字节。

### 5.12 类型 23：波特率修改

```
ID   = (23 << 24) | (host_id << 8) | motor_id
Data = 0x01 0x02 0x03 0x04 0x05 0x06 F_CMD 0x00
```

F_CMD：`01`=1M，`02`=500K，`03`=250K，`04`=125K。**重新上电生效。**

### 5.13 类型 24：主动上报开关

```
ID   = (24 << 24) | (host_id << 8) | motor_id
Data = 0x01 0x02 0x03 0x04 0x05 0x06 F_CMD 0x00
```

F_CMD：`00`=关闭（默认），`01`=开启，默认间隔 10 ms（可用 `EPScan_time` 调整）。

### 5.14 类型 25：协议切换

```
ID   = (25 << 24) | (host_id << 8) | motor_id
Data = 0x01 0x02 0x03 0x04 0x05 0x06 F_CMD 0x00
```

F_CMD：`0`=私有协议（默认），`1`=Canopen，`2`=MIT 协议。**重新上电生效。**

## 7. 控制模式与初始化顺序

**电机上电后默认处于运控模式（run_mode=0）。**

### 7.1 运控模式（默认）

```
使能(类型3) → 运控指令(类型1) → 收反馈(类型2)
```

### 7.2 电流模式（run_mode=3）

```
写 run_mode=3 (类型18) → 使能(类型3) → 写 iq_ref (类型18)
```

### 7.3 速度模式（run_mode=2）

```
写 run_mode=2 → 使能 → 写 limit_cur → 写 acc_rad → 写 spd_ref
```

### 7.4 位置模式 CSP（run_mode=5）

```
写 run_mode=5 → 使能 → 写 limit_spd → 写 loc_ref
```

### 7.5 位置模式 PP（run_mode=1）

```
写 run_mode=1 → 使能 → 写 vel_max → 写 acc_set → 写 loc_ref
```

> 手册 §注意事项：**运行中不可切换控制模式**，必须先发停止（类型 4）再切。

### 7.6 推荐上电流程

```
1. CAN 初始化：1 Mbps、扩展帧、正常模式
2. 类型 0 确认电机在线
3. 需要时写 run_mode，再类型 22 保存
4. 类型 3 使能
5. 循环：类型 1 控制 + 类型 2 反馈
6. 退出：类型 4 停止
```

## 8. 零点与标定

- 默认 `zero_sta=0`，上电位置范围 `0~2π`；设为 1 则 `-π~π`，改完需类型 22 保存。
- 标零：类型 6，`Byte0=0x01`。**CSP 和运控模式可标零，PP 模式会屏蔽。**
- `add_offset`：在当前零点基础上加偏置。例如在 1 rad 处标零后设 `add_offset=1`，重新上电后原 1 rad 位置变为 1 rad。
- `damper=1` 可取消关机后的反驱阻尼保护（快速反驱时会有阻尼感，属正常保护）。

## 10. 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全没反应 | 用了标准帧 | 必须扩展帧 |
| 没反应 | 波特率不是 1 Mbps | 确认总线 1 Mbps |
| 收到帧但不动 | 没使能 | 先发类型 3 |
| 数据全是乱值 | 大端/小端混用 | 类型 1/2 用大端，类型 17/18 用小端 |
| 增益差 2 倍 | 手动写了 `*0x7FFF` | 用 `float_to_uint(x, min, max, 16)`，跨度 65535 |
| 力矩没生效 | 力矩放在数据区 | 力矩在 **ID 的 bit23–8** |
| 改完参数重启丢失 | 没发类型 22 | 保存帧数据是 `01..08` |
| 标零无效 | 当前是 PP 模式 | 切到运控或 CSP 再标零 |
| 总线错误多 | 缺 120Ω 终端电阻 | 两端各一个 |
| 上电乱动 | 零点不对 | 先确认 `zero_sta` 和机械零位 |
